# Приложение «Список дел» (Note App)

Простое приложение для ведения списка задач с возможностью отмечать выполненные пункты.

## Особенности

- Добавление новых задач.
- Отметка задач как выполненных (перечёркнутый текст). #Эта функция будет добавлена в следующих релизах
- Удаление завершённых задач.
- Чистый минималистичный интерфейс.
